## Running Graded assignment 02

Run commands from this project folder in the GA01 Conda environment (Python, PyTorch, NumPy, pandas, and matplotlib). The project uses the existing GA01 dependencies; no TensorFlow installation is needed.

```bash
# 1. Activate your GA01 environment (replace <ga01-env> with its name)
conda activate <ga01-env>

# 2. Open this folder in the terminal, then check the PyTorch agent
python run.py check

# 3. Optional: run a short pipeline smoke test
python run.py quick

# 4. Reproduce the full v17.1 training (200,000 iterations)
python run.py train

# 5. Regenerate the learning-curve plot
python run.py plot

# 6. Visualize the final saved policy (GIF; no ffmpeg required)
python run.py play --iteration 200000 --games 5 --format gif

GPU is used automatically when CUDA is available; CPU is supported.

## Assignment and implementation

This project ports the `DeepQLearningAgent` in `agent.py` from the TensorFlow/Keras Snake RL codebase to PyTorch, using model version 17.1. The main graded implementation is the CNN-based DQN agent. The environment, replay buffer, training loop, configuration, and visualization are retained or adjusted only where needed to run the port.

The agent uses two consecutive 10×10 board frames as input and predicts Q-values for four actions. It masks illegal actions, samples transitions from replay memory, learns with a target network, and saves PyTorch `state_dict` checkpoints. The network has 122,068 trainable parameters.

### Training flow

1. `training.py` advances 128 parallel games and collects transitions.
2. `replay_buffer.py` stores transitions; each optimization step samples a batch of 64 from a buffer with capacity 80,000.
3. `agent.py` computes the legal-action Bellman target with the target network and applies a Huber-loss update with RMSprop.
4. Every 500 iterations, training evaluates eight games, synchronizes the target network, writes a CSV row, saves a checkpoint, and decays epsilon by 0.97 (down to 0.01).

The board dataset is generated by `obstacles_board_generator.py`. It contains 40,008 stored records, with eight obstacle cells per board and 23,332 unique layouts.

## Results and supplied artifacts

The supplied final checkpoint was trained for 200,000 iterations. In `model_logs/v17.1.csv`, the final 8-game evaluation reports mean reward **18.88** and mean snake length **21.88**. Across the final 10,000 iterations, the mean logged reward is **15.12** and mean length is **18.12**. Each evaluation point contains only eight games, so individual values are noisy and should not be read as a guarantee of performance on every board.

## Notes on the PyTorch port

- Keras NHWC inputs are transposed to PyTorch NCHW in the agent; the environment and replay buffer remain NumPy-based.
- Glorot-uniform initialization, RMSprop settings (`lr=5e-4`, `alpha=0.9`, `eps=1e-7`), and mean Huber loss (`beta=1`) are set explicitly to match the source behavior.
- The target uses legal next actions only. Non-finite maxima are handled before terminal masking to avoid invalid `NaN` targets.
- Checkpoints are PyTorch `state_dict` files (`.pt`), not TensorFlow `.h5` files.
